# Thomas Restaurant

Website for Thomas Restaurant, Salmiya, Kuwait.

Domain: thomasrestaurant.com (registered; deployment and DNS connection pending).

## Confirmed scope

- Thomas portal with Korean and Chinese entrances.
- English / Arabic switch on every page; Arabic right-to-left layout.
- Korean: verified menus, prices, events, location and WhatsApp reservation requests.
- Chinese: renovation notice, chef profile and upcoming dishes only.
- Opening event: Mukbang Show teaser; applications open only after dates and terms are confirmed.

## Development

The repository starts with documentation. Implementation changes use feature branches and pull requests. Production deployment is not configured yet.

No customer records, applicant videos, passwords, API tokens or private operational documents belong in this public repository.
